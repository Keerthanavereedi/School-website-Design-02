# Green Valley International School Website

A modern and responsive school website designed using HTML and CSS.

## Features

- Home page
- About the School
- Academics
- Admissions
- Achievements
- Events
- Faculty
- Gallery
- Contact page
- Sitemap
- Responsive and user-friendly design

## Technologies Used

- HTML
- CSS

## Project Purpose

This project was created to design a professional school website that provides students, parents, and visitors with easy access to information about the school, academics, events, admissions, faculty, and achievements.
